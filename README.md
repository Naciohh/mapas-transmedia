# Mapas transmedia · Desinfo

Web con las tres versiones del mapa transmedia de la campaña, con un selector arriba:

- **TP1 · Original** (el TP2 no lo cambió)
- **TP3 · Teles**
- **TP4 · Evento** (abre por defecto)

Cada una se puede enlazar con `#tp1`, `#tp3` o `#tp4`. Es una página estática (`index.html`), sin build: se publica tal cual en Vercel (`vercel.json`).

Los SVG de `exportados/` son la versión TP4 en tema claro y oscuro. El detalle de los cambios del TP4 está en [CAMBIOS_TP4.md](CAMBIOS_TP4.md).
